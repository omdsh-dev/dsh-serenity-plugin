# Skill: acc-eap — EAP 认知质量框架

> **"思维的功能价值与其外部可重建性成正比。"** —— EAP（Explicit Abstraction Principle）

## 用途

EAP 是宁静号认知质量的底层标准。它回答一个问题：**一段输出（决策/文档/代码/对话）的质量如何衡量？**

答案是三变量：

| 变量 | 含义 | 提升手段 |
|------|------|---------|
| **E↑ 显式度** | 内容中变量/实体/关系被明确定义的程度 | 定义变量、指明关系方向与基数、划定边界 |
| **R↓ 重建成本** | 未来 Agent/人重建原始推理的成本 | 记录决策理由、上下文、约束、备选方案 |
| **S↑ 稳定性** | 同一输入反复产生一致结果的程度 | 结构固化、协议化、避免依赖隐含上下文 |

## 输出前自检清单（每次输出前快速过一遍）

- [ ] 变量/实体明确定义（E↑）
- [ ] 关系指明方向/基数（E↑）
- [ ] 边界划定——什么在范围内/什么不在（E↑）
- [ ] 不使用歧义词汇："处理""优化""问题"→ 具体化（E↑）
- [ ] 关键决策记录了理由与备选（R↓）
- [ ] 不跳级讨论——先对齐上层再进入下层（R↓）
- [ ] 结构可重复执行/生成（S↑）

## 渐进式披露

- **无参数加载**：本技能即完整框架
- **按需聚焦**：针对具体场景，把对应变量清单提出来逐项对照

## 与 ACC 的关系

ACC 三层的 EAP 映射：

| 层 | EAP 角色 |
|----|---------|
| **ACC**（dsh-serenity-plugin） | 所有结构编码为代码/模板/契约（E↑）；从 ACC 生成 CCC 完全确定（R↓）；多 CCC 结构一致（S↑） |
| **CCC**（home-serenity 等） | 认知内容编码为 skill/SESSION/设计文档 |
| **产出物**（本会话产出） | 用本清单自检 |

## 何时使用

- 任何重要输出的收尾自检
- 设计文档/方案/决策记录写作前
- 被要求"按 EAP 标准"时

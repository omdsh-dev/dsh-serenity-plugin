## 一、这张表是什么、为什么还活着

轨迹（trajectory）↔ dsh 会话的**绑定**有两处持久化载体：

| 载体 | 位置 | 角色 |
|---|---|---|
| **宿主存储域**（D68 起为权威） | `~/.dsh/storages/serenity_bindings.json`（unit 名 `serenity_bindings`） | **权威**；**全局单表**（跨 CCC 同表，各条按 `mdPath` 自然分区） |
| **旧文件**（本文件的对象） | `<CCC 根>/AGENT_SESSIONS/.bindings.json` | **回落兜底**；**每 CCC 一份** |

现状 = **双写**。`appendBound` 的注释逐字写着：

> `§0L 双写：域（权威，异步落盘 fire-and-forget）+ 旧文件（兜底，同步）`

旧文件侧的定位同样是注释里写死的：「**永久保留**：owner「向前兼容」的第二道保险」。
⇒ **"废除"要动的正是这道保险**，所以必须先证明它**没有携带独有信息**。

## 三、② 代码面清账（谁写、谁读）

全部在 `src/trajectory-bound.ts`，常量 `BINDINGS_REL_PATH = 'AGENT_SESSIONS/.bindings.json'`。
> 🔵 下表的**函数名是符号锚**；行号只作「某版本的实测读数」，不作引用依据。

### 写方（3 处 —— 全部经 `writeBindingsFile`）

| 函数 | 写什么 |
|---|---|
| `appendBound` | 写本会话记录 ＋ 把**同轨迹其它条**标 `supersededAt`（**同一次 RMW**；它自 2026-09-21 起同时是 D69「只留一条」的**唯一写入口**） |
| `supersedeOtherBindings` | 只标 `supersededAt`（判据 = 域 ∪ 文件的并集） |
| `pruneMissingBindings` | 删除指向已不存在会话的记录（判据 = 域 ∪ 文件的并集，`isMissing` 必须 fail-closed） |

### 读方（3 处）

| 函数 | 读法 |
|---|---|
| `readLastBound` | **三级回退**：① 域 → ② 旧文件 → ③ 旧事件形态（`readLegacyBoundFromEvents`，兼容 v1.30.5 及更早） |
| `listBoundSessionIds` | 域优先；**域给出 0 条时仍回落文件**（注释写明是"迁移期"语义）；这是 `wake-scheduler` 冷唤醒**选人的唯一入口** |
| `migrateBindingsToDomain` | 一次性把某 CCC 的旧文件**全量灌入**域（由 `ensureBindingsMigrated` 在启动期调用） |

⇒ 旧文件**同时占据读面的第②级与写面的同步载体**。
**「停写」= 去掉上表三个 `writeBindingsFile` 调用；读面可以原地不动。**

## 四、③ 退休形态：三选一（**实现前必须先定的那个决策**）

🔴 **关键风险 —— "停写"不等于"安全"**（本条为对账过程中新发现，必须点名）：

若**只停写、却把旧文件留在盘上**，它会**冻结在切换时刻**：此后域侧发生的
`supersededAt` 退休、`pruneMissingBindings` 删除，**都不会再反映到这份回落面上**。
⇒ 一旦域日后不可用（宿主升级改位置 / 格式不兼容），回落到的是**冻结的旧表**，
可能把**已经退休的载体**当成活载体返回给 `listBoundSessionIds`
⇒ **静默选错会话**（症状与"这条轨迹没有可用会话"完全不同，更难发现）。

| 形态 | 做法 | 失败面 |
|---|---|---|
| **(i) 停写 + 删除旧文件** | 迁移完成后删除（或改名 `.retired` 留档） | 域不可用时**回落面为空** = 与"全新 CCC"同语义：**只是少一层保险，不会给错答案** |
| **(ii) 停写 + 保留冻结副本** | 什么都不删 | 存在**复活已退休载体**的窗口（上述风险）；需另加"冻结面不可信"判据才安全 |
| **(iii) 停写 + 保留读 + 写退休标记** | 迁移完成时在旧表写入"已退休"标记，读面据此拒绝 | 读面需改判据；信息最全但改动面最大 |

**倾向 (i)** —— 理由：① 与 owner 逐字「**不再写了，需要废除**」语义一致；
② **唯一失败面是"少一层保险"，而不是"给错答案"**（安全的方向正确）；
③ 改动最小（只删三个写调用 + 切换日删文件）。

⚠️ **但 (i) 需要 owner 确认一件事**：**"向前兼容的第二道保险"是否就此撤销** ——
那是他当初明确要求保留的东西 ⇒ 撤销它属于**语义变更**，不是纯实现细节。
